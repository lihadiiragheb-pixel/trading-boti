# دليل تشغيل بوت التداول على منصة MEXC (صفر عمولة)

هذا البوت تم تعديله ليعمل على منصة **MEXC** لتجنب عمولات التداول المرتفعة، مع إضافة فلتر **RSI** لتحسين جودة الصفقات.

## 🚀 المميزات الجديدة
- **صفر عمولة:** يعمل على سوق MEXC Spot (0% Fee).
- **فلتر RSI:** لا يدخل الصفقات إلا في اتجاه الزخم القوي.
- **إطار 5 دقائق:** تقليل الضوضاء السعرية والصفقات العشوائية.

## ⚙️ الإعدادات المطلوبة (Environment Variables)
يجب إضافة المتغيرات التالية في منصة التشغيل (Render أو VPS):

| المفتاح (Key) | الوصف |
| :--- | :--- |
| `MEXC_API_KEY` | مفتاح الـ API من MEXC |
| `MEXC_API_SECRET` | السر (Secret) من MEXC |
| `SYMBOL` | زوج العملات (مثلاً: `BTC/USDT`) |
| `TIMEFRAME` | الإطار الزمني (`5m`) |
| `RISK_PCT` | نسبة المخاطرة (`0.01` تعني 1%) |
| `TELEGRAM_BOT_TOKEN` | توكن تلجرام للإشعارات |
| `TELEGRAM_CHAT_ID` | معرف المحادثة في تلجرام |

## 🛠️ ملف التشغيل الجديد
استخدم ملف `improved_equal_levels_bot_mexc.py` للتشغيل الأساسي.
