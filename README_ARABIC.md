# دليل تشغيل بوت التداول على منصة Render

هذا البوت مجهز للعمل بشكل آلي 24/7 على منصة **Render** باستخدام استراتيجية **Equal Levels**.

## 🚀 خطوات التشغيل

### 1. الرفع على GitHub
1. قم بإنشاء مستودع (Repository) جديد على حسابك في GitHub.
2. ارفع جميع الملفات الموجودة في هذا المجلد إلى المستودع.

### 2. الإعداد على Render
1. سجل الدخول في [Render.com](https://render.com).
2. اضغط على **"New +"** ثم اختر **"Background Worker"**.
3. اربط حسابك بـ GitHub واختر المستودع الذي رفعته.
4. استخدم الإعدادات التالية:
   - **Name**: `trading-bot-v1` (أو أي اسم تفضله).
   - **Runtime**: `Python 3`.
   - **Build Command**: `pip install -r requirements.txt`.
   - **Start Command**: `python bot_runner.py`.

### 3. إضافة مفاتيح API (خطوة هامة جداً)
في لوحة تحكم Render، اذهب إلى قسم **"Environment"** وأضف المتغيرات التالية:

| المفتاح (Key) | القيمة (Value) |
| :--- | :--- |
| `BINANCE_API_KEY` | مفتاح الـ API الخاص بك من بايننس |
| `BINANCE_API_SECRET` | السر (Secret) الخاص بالـ API |
| `SYMBOL` | زوج العملات (مثلاً: `BTCUSDT`) |
| `TIMEFRAME` | الإطار الزمني (مثلاً: `1m`) |
| `RR_RATIO` | نسبة الربح للخسارة (مثلاً: `2.0`) |
| `RISK_PCT` | نسبة المخاطرة (مثلاً: `0.005` تعني 0.5%) |
| `TELEGRAM_BOT_TOKEN` | التوكن الخاص ببوت تلجرام (من @BotFather) |
| `TELEGRAM_CHAT_ID` | معرف المحادثة الخاص بك (من @userinfobot) |

## ⚠️ ملاحظات هامة
- **وضع المحاكاة**: إذا لم تضف مفاتيح API، سيعمل البوت تلقائياً في وضع "التداول الوهمي" (Paper Trading) ولن ينفذ صفقات حقيقية.
- **التكلفة**: منصة Render تقدم خطة مجانية، ولكن للتشغيل المستمر 24/7 قد تحتاج للخطة المدفوعة البسيطة (حوالي 7$ شهرياً) لضمان عدم توقف البوت.
- **الأمان**: لا تضع مفاتيح الـ API داخل الكود أبداً، استخدم دائماً قسم **Environment Variables** في Render.
