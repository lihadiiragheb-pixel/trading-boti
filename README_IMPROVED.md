# 🤖 دليل استخدام بوت التداول المحسن (Trading-Boti v2.0)

تم تطوير هذه النسخة لمعالجة العيوب التقنية والاستراتيجية في النسخة الأصلية، مع التركيز على **الدقة، الأمان، واستمرارية العمل**.

## 🚀 التحسينات الرئيسية

### 1. محرك الاستراتيجية (Strategy Engine)
*   **التسامح السعري (Price Tolerance):** إضافة نسبة سماح (`level_tolerance_pct`) عند رصد المستويات المتساوية، مما يسمح برصد الدعم والمقاومة حتى لو لم تتطابق الأسعار بالسنت الواحد.
*   **نافذة تحليل أوسع:** توسيع نافذة البحث عن القمم والقيعان لتقليل الإشارات الخاطئة الناتجة عن ضوضاء السوق.
*   **فلترة الاتجاه:** استخدام متوسط متحرك بسيط (SMA 50) لضمان التداول مع الاتجاه العام فقط.

### 2. إدارة المخاطر (Risk Management)
*   **حفظ الحالة (State Persistence):** إضافة نظام حفظ تلقائي لحالة الصفقات في ملف `trade_manager_state.json`. في حال توقف البوت أو إعادة تشغيله، سيستعيد كافة بيانات الصفقات المفتوحة والإحصائيات اليومية.
*   **أهداف يومية صارمة:** إضافة حدود للربح والخسارة اليومية (`daily_profit_target`, `daily_loss_limit`). يتوقف البوت عن فتح صفقات جديدة فور الوصول لهذه الحدود.
*   **تتبع الوقف الذكي (Trailing Stop):** تحسين منطق تتبع الوقف لتأمين الأرباح بشكل تدريجي مع حركة السعر.

### 3. استقرار النظام (System Stability)
*   **التراجع التدريجي (Exponential Backoff):** إضافة آلية إعادة محاولة ذكية عند فشل الاتصال بواجهة برمجة تطبيقات بايننس (Binance API) لتجنب الحظر أو التوقف المفاجئ.
*   **صلاحية ديناميكية:** حساب وقت انتهاء صلاحية إشارات إعادة الاختبار (Retest) بناءً على الإطار الزمني المستخدم.

## ⚙️ الإعدادات الجديدة (Environment Variables)

يمكنك الآن التحكم في المعلمات التالية عبر متغيرات البيئة:

| المتغير | الوصف | القيمة الافتراضية |
| :--- | :--- | :--- |
| `LEVEL_WINDOW` | عدد الشموع للبحث عن القمم/القيعان | `5` |
| `LEVEL_TOLERANCE_PCT` | نسبة السماح لتطابق الأسعار | `0.0005` (0.05%) |
| `DAILY_PROFIT_TARGET` | هدف الربح اليومي (نسبة من الرصيد) | `0.05` (5%) |
| `DAILY_LOSS_LIMIT` | حد الخسارة اليومي (نسبة من الرصيد) | `0.02` (2%) |

## 🛠 كيفية التشغيل

1.  تأكد من تثبيت المكتبات المطلوبة: `pip install -r requirements.txt`
2.  قم بضبط مفاتيح API في متغيرات البيئة.
3.  شغل البوت باستخدام: `python bot_runner.py`

---
**تنبيه:** التداول بالعملات الرقمية ينطوي على مخاطر عالية. استخدم البوت في الوضع التجريبي (بدون مفاتيح API) أولاً للتأكد من ملاءمة الإعدادات لاستراتيجيتك.
